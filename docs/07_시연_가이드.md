## 2분 시연 순서 (검증된 경로)
1. `@재무봇 우리 밸류에이션 얼마였지?` → 🧠 근거 각주 → **각주 클릭**(원본/상세)
2. 답변 👍 → 사이드바 📚(위키: 검색+기여 통계) → 에이전트 클릭(다이얼로그·🔒마스킹·출처)
3. `/import`에 카톡 txt 붙여넣기 → 지식 등록 → 과거 질문 → 근거 답변 (아하 모먼트)
4. `/metrics` → 실지표 카드
- 여유 시: 🌙 테마 · 👥 멤버 관리 · 빈 채널 CTA · `/discuss`(4인 캡)
