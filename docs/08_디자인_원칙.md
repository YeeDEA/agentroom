# 디자인 원칙 (2026-08-12 · 레퍼런스 리서치 ⑤의 산출물)

## 유지해야 할 것 (현재 화면의 자산)
1. 신뢰 배지(근거 각주·🔒마스킹·⚠️신뢰낮음·팀기억미사용)는 항상 일급 요소
2. 라이트 업무 톤 + 파스텔 펫 균형 — 게임틱 회귀 금지
3. 기능은 버튼 추가가 아니라 `/` 명령어로
4. 모든 산출물은 doc 카드 문법으로
5. 상시 점유 UI 금지(다이얼로그 원칙)

## 적용 기준 5 (모든 화면 변경 시 체크리스트)
1. **빈 화면은 명령문 주행동 1개** — "~가 없어요/선택하세요" 금지 (Linear 반온보딩)
2. **신뢰 신호는 선불** — 출처·마스킹은 답의 앞/안에 (Perplexity)
3. **활성화 경로(가입→백필→첫 질문→근거답변)로 안 가는 UI는 뒤로** — 펫·EXP는 첫 세션 소음
4. **행동 직후 다음 행동 제안** — 답변 뒤 후속 질문 칩(미구현·백로그), 백필 뒤 "이걸 물어보세요"
5. **실패는 원인+복구 한 쌍** — "안 됐어요"로 끝나는 문구 금지

## 레퍼런스 3 (구조만 차용, 복제 금지)
- **Perplexity**: 소스 스트립·인라인 칩·답변 후 후속질문 — 근거 UX의 표준
- **Linear**: 빈 화면=시작점(주행동 1개+맥박), 팔레트 중심 — 단 무채색 전문가 미학은 배제
- **임포트형 SaaS(Readwise류)**: 활성화에서 역산, 변환 전 미리보기, 내보내기 안내 내장 — 관료적 다단계는 배제

## 현재 디자인 시스템 (구현 완료 · agentroom.css V1~V8 레이어)
CSS 하단에 V1~V8 블록으로 누적. 되돌리려면 해당 블록만 삭제.

- **서체**: Pretendard Variable (CDN)
- **팔레트(라이트)**: 종이 `#faf9f5` · 잉크 `#211f1a` · 진초록 accent `#2e6e4e` · 검증초록 `#2e8b57`. 다크는 재계산본. "AI-보라 SaaS" 탈피, "기억 보관소" 톤
- **색 의미 분리**: `--c-agent`(AI) / `--c-human`(사람) / `--c-verified`(근거 검증)
- **토큰**: 스페이싱 `--sp-1~6`(4배수), 이징 `--ez-out`·클릭 120ms·시스템 240ms
- **타이포 3층위**: 본문 15/1.62 · 근거칩 12.5/tabular · 메타 11/tracking
- **레이아웃**: 3단 디스코드 골격 → **2단**(워크스페이스 레일이 사이드바 위 가로 스트립, grid-areas)
- **말풍선 = 포스트잇**: 에이전트=노랑(-0.5° 기울기·접힌 모서리), 나=민트(+0.6°), 승격=초록 테이프. hover 시 펴짐
- **방 아이콘**: 자연물 한 획 라인아트 10종(나비·잎·낙엽·물결·새싹·산·물방울·꽃·조개·눈송이), 이름 해시 배정
- **카드 = 서류/인덱스**: 왼쪽 색 탭으로 종류 구분(백필 슬레이트·지표 골드·회의 플럼·요약 클레이·안내 청록·기본 진초록), 제목 이모지 제거
- **아이콘**: UI chrome 이모지 전부 stroke SVG(📚👥🌙⚙️⎋✨📎👍👎🧠📋🗑＋). **에이전트 픽셀 펫만 이모지·캔버스 유지**
- **모션(정적 탈피, 산뜻 유지)**: 메시지 슬라이드 등장, 포스트잇 hover, 에이전트 아바타 4초 호흡(유일 무한반복, reduced-motion 존중), 승격→📚 위키 종이조각 비행, 팔레트 슬라이드업, 버튼 눌림
- **후속 질문**: 채팅에 안 뿌리고 ✨ 버튼 아래로 통합(마지막 답변 followups 우선, LLM 없이 즉시)
