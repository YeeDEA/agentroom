# 창업자 미션 (2026-08-12 · 이키가이 문답 ④의 산출물)

## 이키가이 4관점 (사실/희망 구분, 억지 교집합 없음)
- **좋아함**: 신기술로 뭔가 만들어질 때의 몰입(5주 실증) + 인정. ⚠️ 발상은 고됨("아이디어 내는 게 항상 힘들었어")
- **잘함(사실)**: AI 지렛대 개발 속도(팀원 인증·5주 15배포) · 신호/시스템/확률 기초(전과목 A+) · 자산: GDG 회장직(25명 결정권)·코드베이스
- **세상의 어려움(관찰)**: ① 권하진 — 카톡에서 팀플 자료 못 찾음 ② **사람들이 에이전트를 어떻게 활용할지 몰라 고생(반복 목격)**. ⚠️ 관찰 근육 자체가 미발달
- **대가 지불(검증)**: 빈 칸 — GDG 서버 대여 1건뿐(결재 스토리 확인 = 대표 숙제)

**판정**: 완전한 이키가이는 아직 미성립(아래 두 칸이 얇음). 채우는 방법 = 코드가 아니라 관찰·판매 시도.

## Mission 후보 3
| | Mission | 근거 |
|---|---|---|
| M1 | 매년 사람이 바뀌는 팀의 "작년 지식이 카톡에 파묻힌 상황"을 → 물으면 근거와 함께 답이 오는 상태로 | 중 (제품 존재·권하진 1건 / 반증: 재방문 0) |
| **M2** | 에이전트를 어떻게 써야 할지 모르는 사람의 "막막한 첫 시작"을 → 따라 하면 되는 실전 흐름으로 | **강** (반복 목격+본인이 산증인+GDG 채널) |
| M3 | 발상이 고된 빌더의 "뭘 만들지 막막함"을 → AI가 발상을 대신 지는 흐름으로 | 약 (표본 1=본인) |

## 결론
- **근거 최강 = M2.** 단 M2는 AgentRoom 폐기가 아님 — 가이드봇·✨추천·재방문 0이 정확히 M2의 문제.
- **GDG 4주 도그푸딩이 M1과 M2를 동시 검증**: 25명이 막히는 지점이 "기능이 없어서"면 M1, "뭘 물을지 몰라서"면 M2가 본체.
- 이번에 만들지 않을 것: M3용 신제품 · 에이전시용 무엇이든 · 인프라 · (당시 기준) PRD 대규모 빌드
