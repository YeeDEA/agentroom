# 기억 회수 골든셋 (v1 · 2026-08-12)

회수 랭킹(게이트·가중치) 튜닝용 평가셋. LLM 호출 없이 랭킹 함수만 돌려
밀리초 단위로 평가한다. 지식이 바뀌면 정답 라벨을 갱신할 것.

- 평가 지표: precision@1(1순위가 정답), recall@4(top4 안에 정답), missAcc(무관 질문에서 0건 주입)
- 종합점수 = 0.5·p@1 + 0.3·r@4 + 0.2·missAcc

## 튜닝 이력

| 일자 | 설정 | p@1 | r@4 | missAcc | 비고 |
|---|---|---|---|---|---|
| 2026-08-12 | gate 0.06 / rel .65 / rec .20 / prom .15 | 78% | 94% | 100% | 초기값 |
| 2026-08-12 | **gate 0.12** / rel .65 / rec .20 / prom .15 | **83%** | 94% | 100% | 채택 — 게이트 상향만으로 개선. wRel은 .55~.75 구간 무차별 |
