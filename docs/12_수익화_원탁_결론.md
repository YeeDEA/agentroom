## 최종 결정 6건

### Q1. Pro 가치 축 — "기억의 영속성" 3종으로 확정
- **넣는다**: ①백필 무제한(횟수·메시지·방) ②영구 기억(동면 해제 + **결제 즉시 동면 지식 일괄 부활** — 부활 모먼트를 결제 직후 화면에 시각화) ③인수인계 위키 스냅샷 무제한
- **뺀다(확정)**: 좌석 제한(전 플랜 무제한) · 입력 한도 일체 · 답변 품질/속도/모델 차등 · PII 마스킹 과금 · '우선 지원' filler
- 무료에도 **스냅샷 첫 1회 내보내기 유지** — 데이터 이탈권 인질화 금지("삭제 아님" 약속과의 정합)
- 모달 카피: "기능 잠금 해제" 금지 → **"지금 잠들어 있는 기억 N개 깨우기"(실수치)**
- 패키징 한 줄: "Free = 이번 학기의 기억, Pro = 팀의 역사 전체"

### Q2. 에이전시 상품 — 좌석 폐기, "클라이언트 방 × 보존"으로
- **1인 9,000원×5석 공식 폐기.** 가설 가격: **Business 월 79,000원(방 5개·좌석 무제한·영구 보존) + 방당 월 12,000원** → 평균 10방 ARPA 연 ~144만원
- 킬러 기능 = **방별 청구 내역서(PDF/엑셀)**: 방당 비용을 클라이언트 리테이너에 실비 전가 → 회계 승인 자동화
- 종료 클라이언트 방은 읽기전용 무료 보존·재계약 시 부활. 학생 가격표와 **페이지·단위 완전 분리**(4,900원 앵커 차단)
- ⚠️ 접촉 0 — **모의 견적서 2안(79,000 번들 vs 29,000 저가) 5곳 발송**으로 검증 전까지 전부 가설

### Q3. 결제 검증 — 선입금 전면 기각, "결재권자 서명 확약서" 사다리
- 사전예약금·선불 바우처 **기각(만장일치)**: PG 미등록 + 전자상거래/전자금융 리스크 + 다크패턴화
- 사다리: [1] 모달 3단 의향(알림 클릭→팀·용도→**'출시 시 결제' 체크+결재권자 실명**) step 계측 → [2] 학생: **확약서**(회장+총무 서명·결제개시일·결재경로 기입·무위약 해지 명문) + **차기 예산안 49,000원 편성 인증**(총회 의결 캡처) → [3] 실입금은 **사업자등록+통신판매업 신고+plan 서버 검증** 3조건 후 에이전시 3개월 선불 30만원 계좌이체(세금계산서·전액환불 명문)만
- 통과선: 컨시어지 5팀 중 3팀 서명. 모든 화면에 "지금은 아무 금액도 청구되지 않습니다" 상시 표기
- **다크패턴 금지 5칙**: 가짜 희소성/카운트다운 금지 · 이행 계획 없는 할인 약속 금지(기존 "50% 할인" 문구는 이행 각서 또는 '얼리버드 우대'로 완화) · 무청구 상시 고지 · 철회 원클릭 · 학생 대상 마감 압박 금지

### Q4. 무료 한도 — 골격 유지 + 3수정
- 백필 1회/ws 유지(만장일치). **'최근 500' → '사용자 구간 선택 500'**(인수인계 맥락에서 최근 500=방학 잡담, 맛보기 실패) + **잘림 카운터**("23,412개 중 500개 상속 · 잠긴 결정 후보 74건") 필수 — 이것이 upgrade_intent 엔진
- 500 존폐는 GDG 데이터 판정 규칙으로: first_cited_answer 도달률 ≥60% & 잘림 기인 차단 ≤10%면 유지, <40%면 2,000 상향
- 90일 동면 유지(180일이면 한 기수가 통째 무료 → 전환 사유 소멸). 단 **'인용 지식 나이' 섀도 계측** 즉시 추가, 8~12주 후 재판정. D-14 예고 배너에 "삭제되지 않습니다" 명문
- 시즌 한정 무료 완화 **금지**(Pro 가치 붕괴) — 시즌은 Q5 패키지로 해소
- 참고(코드 사실): 동면 시계는 백필 시점 createdAt 기준 — "백필 즉시 동면" 우려는 전제 오류

### Q5. 인수인계 시즌 오퍼 — 연 49,000원 선불 단일 SKU
- **"인수인계 패키지" = 학생 Pro 연간의 시즌 재포장**(별도 상품 아님): 기수 전체(≤3년) 백필 + 12개월 영구 기억(임기 일치, 만료 시 동면 복귀 고지) + 위키 스냅샷(승격 Top30+근거 PDF) + 대표자 이관 + **견적서·지출결의서 템플릿 동봉**
- 근거: 총무 전결 한도(통상 5만원) 바로 아래 · 감사 허용선(예산 3~5%) · 결제주기=임기 1년 → 갱신이 다음 인수인계 시즌에 자연 낙하
- 카피 이원화: 떠나는 회장("유산을 남긴다"·무료 백필) / 오는 회장("막막함 해소"·결제). 오퍼 문구: **"3년치 단톡방을 49,000원에 다음 기수로"**
- 판매창(실제 캘린더 근거만): 11/15~12/15, 1/15~3/15. **2026-12 = 확약서·컨시어지만, 2027-02 = 첫 실결제**(목표 20팀 — 매출 아닌 전환율 데이터가 목적)
- 유통=동아리연합회(공문+임원 OT 슬롯), 결제=동아리 단위. 갱신 안건 자동 상정 문구+계정 양도 절차를 리포트에 내장(1년 일회성 매출 방지)
- 예비안: 2027-02 가격 저항 시 일회성 19,900원 '인계 패스' 하위 SKU 재도입

### Q6. 100억 산술 — 3축 재구성 ("4,900×17만 팀" 폐기)
| 축 | 금액 | 산술 | 지위 |

| 학생 | ~2-5억 (2-5%) | 연 49,000 × 5천~1만 팀 | **실험실+레퍼런스 공장** (KPI=상속 스토리·졸업생 반입 건수, 매출 아님) |

- 원가는 병목 아님(답변당 1~2원, 총이익률 85%+)

4. 10~11월 준비 → 11/15~12/15: 확약서+예산 편성 인증 수집 (5팀 중 3팀 = 통과)
