# 수익화 설계 (2026-08-12 · PLG+행동경제 패널 합의)

## 원칙 (결정로그 확정)
1. **기능을 잠그지 않는다 — 자산의 회수에 한도를 건다.** 안 써본 기능은 감정가 0원, 이미 쌓인 기억엔 소유 효과·손실 회피가 걸린다.
2. **입력(질문·승격·위키·👍👎)은 영원히 무료.** 기여 행위 과금 = 공정성 위반 = 최악의 게이트.
3. 먼저 무제한으로 쌓게 하고, 나중에 열람에 한도. 삭제라 말하지 않는다 — **동면(❄️)**.

## 티어
| | Free | Pro (팀당 월 4,900원 · 커피 준거점) |
|---|---|---|
| 카톡 백필 | 1회 · 최근 500메시지 | 무제한 |
| 지식 열람 | 최근 90일 (이후 동면) | 영구 |
| 에이전트 | (현재 미강제) | 3 |
- 에이전시: 1인 9,000원·5인 최소 (미구현·미검증)
- 근거: 500메시지≈한 달치 → 아하는 겪고 "작년"에서 벽. 90일 → 3월 백필 팀이 6월 회고 때 만료.

## 전환 순간 (구현됨)
질문 → 동면 지식이 게이트 통과 → 답변에 "❄️ 잠든 기억 N개가 이 질문에 답할 수 있었어요 — 깨우기"
→ 모달(보유량 제시→손실 가시화→커피 준거점) → **출시 알림 50% 할인** 클릭 = `upgrade_intent` 계측.
실결제 없음 — 지불 의향부터 측정.

## 카피 규칙
판매자 언어("잠금 해제") 금지 · 위협 어조 금지 · "무료여도 쌓인 지식은 사라지지 않아요" 명시 ·
페이월은 필요 순간(동면 히트)에만.

## 구현 현황
게이트·모달·계측 ✅ / 동면 깨우기 실제 열람·90일 임박 경고 ❌(백로그) /
plan 서버 강제 ❌(실결제 전 필수) / 체험: `proUntil`로 자동 재잠금(데모 계정 08-13 만료)
